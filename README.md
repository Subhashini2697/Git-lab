# Git-lab
# Git and GitHub Practical Exercises

## About the Project
This repository contains practical exercises based on Git and GitHub. It covers repository creation, file tracking, commits, branching, merging, remote repositories, collaboration, and project management.

## Objectives
- To learn Git version control.
- To create and manage local repositories.
- To track and commit file changes.
- To understand branching and merging.
- To work with remote repositories using GitHub.
- To practice collaboration and issue tracking.

## Practical Exercises

1. **Create a Git Repository** – Initialize a local Git repository using `git init`.
2. **Create a File and Track Changes** – Create files and stage them using `git add`.
3. **Commit Changes** – Save changes using `git commit`.
4. **View Commit History** – Display commit history using `git log`.
5. **Undo Changes** – Restore unwanted changes using Git commands.
6. **Create, Switch, and Delete a Branch** – Manage branches using Git.
7. **Resolve a Merge Conflict** – Identify and resolve conflicts between branches.
8. **Git Stash** – Temporarily save and restore uncommitted changes.
9. **Configure a Remote Repository** – Connect a local repository to GitHub.
10. **Clone, Push, and Pull** – Synchronize changes between local Git and GitHub.
11. **Fork and Pull Request** – Contribute changes to another repository.
12. **Collaborative Editing** – Work with multiple contributors in a repository.
13. **GitHub Issues and Project Boards** – Track issues and organize tasks.

## Tools Used
- Git
- GitHub
- Terminal / Command Prompt
- GitHub Web Interface

## Important Git Commands

```bash
git init
git status
git add .
git commit -m "Initial commit"
git log --oneline
git branch
git switch main
git merge
git stash
git remote -v
git clone <repository-url>
git push origin main
git pull origin main
```

## Conclusion
These practical exercises provide hands-on experience with Git and GitHub. They help in understanding version control, managing source code, collaborating with team members, and tracking project progress efficiently.
